## Strict Examiner Evaluation Rubric (Out of 10 Marks)

Har answer ko 6 criteria par judge kiya jaata hai:

| Criterion | Weight | Kya Dekha Jaata Hai |
| :--- | :--- | :--- |
| **1. Technical Correctness** | 3 marks | Kya answer factually sahi hai? (e.g., `crypto.getRandomValues` vs `Math.random`, AES-256-GCM vs hashing) |
| **2. Clarity & Simplicity** | 2 marks | Kya simple, samajhne layak English mein answer diya gaya bina confuse hue? |
| **3. Confidence & Delivery** | 1 mark | Bina ruke, respectful tone ("Sir/Ma'am") mein jawab diya? |
| **4. Project Understanding** | 1.5 marks | Kya student ko pata hai ki yeh concept *SecurePass* mein kis page par kaise kaam karta hai? |
| **5. Code Explanation Ability** | 1.5 marks | Kya exact file ya function (`crypto.ts`, `AuthContext.tsx`, `generatePassword`) ka naam aur logic bata paaye? |
| **6. Honesty About Limitations** | 1 mark | Kya pending features (2FA, Firestore, FastAPI, AI help, 0 commits) ko imandari se accept kiya? |

**Scoring Guide:**
- **8.5 – 10 / 10:** Examiner-ready! Clear, honest, technically accurate.
- **6.5 – 8 / 10:** Achha hai, bas code file/function pointer ya honesty nuance improve karna hai.
- **Below 6 / 10:** Topic ko `02-project-explained-from-zero.md` aur `11-code-walkthrough.md` se dobara padhein.

## Mock Viva Session Format (When Running With AI Examiner)

1. Examiner **ek baar mein sirf EK question** poochega (member ka naam bata kar).
2. Student apna answer type karega (English mein try karein; agar atak jaayein toh Hinglish mix bhi chalega practice ke liye).
3. Examiner:
   - Score dega (`X / 10`),
   - Batayega kya sahi tha aur kya missing tha,
   - Ek crisp **Corrected Short English Answer** + **Simple Hinglish Explanation** dega,
   - Tabhi agla question poochega!
